# AIFP-4 Mesh protocol

Namespace: `/aifp4/mesh/1.0.0`. The binary wire form is CBOR (`cborg`). The JSON API is for humans and integrations. An envelope carries protocol version, UUID message ID, type, source and origin node IDs, optional destination, creation/expiry timestamps, hop count/limit, previous hop, payload type/hash, payload, sender public key and Ed25519 signature. The signature covers a recursively key-sorted JSON representation of every field except `signature`; the CBOR encoding itself is **not** the signing preimage and is not claimed to be COSE or deterministic RFC 8949 CBOR.

Implemented handlers: `PEER_HELLO`, `PAYMENT_FORWARD`, `PAYMENT_RECEIPT` (synchronous response and asynchronous relay), `PAYMENT_ACK`, and `PAYMENT_FAILED`. The type registry reserves `PEER_CAPABILITIES`, `LINK_STATE`, route and reconciliation names for future dedicated handlers; capabilities/link state currently travel as signed advertisements inside HELLO. HELLO carries signed catalogs; peer identity is pinned after first contact. A direct libp2p sender's Noise peer ID is also checked against the learned signed advertisement.

Intent integrity is separate: the original payment fields retain their deterministic SHA-256 hash and sandbox HMAC; the origin signs the hash plus the agent and both original/current policy snapshots with Ed25519. Relay nodes verify this signature and hash. The settlement node verifies again before execution. A receipt binds intent hash, node/transport path, asset, amount and rail reference; the settlement node signs it. The origin checks the receipt signature against its peer registry.

Receivers reject unknown direct peers, mismatched pinned keys, invalid signatures/hashes, expired envelopes, unsupported versions, duplicate message IDs, wrong destination, excessive hops and repeated path nodes. Replay IDs and settlement records survive restarts. Messages are capped at 64 KiB. A new retry creates a new hop envelope; reusing a message ID is rejected. Route traces are reported by relays and are not independently attested by every hop.
