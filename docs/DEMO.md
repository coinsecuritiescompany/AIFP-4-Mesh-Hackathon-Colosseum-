# 3-minute Demo Flow

1. Show the health endpoint and OpenAPI contract.
2. Create a USDC sandbox intent for an AI agent.
3. Show the policy decision, route ranking, deterministic intent hash and authorized state.
4. Execute the intent and show the settlement receipt.
5. Run the offline-queue test to demonstrate local-first behavior.
6. Run the Solana Devnet payment script and open the printed Explorer link.
7. Show the transaction memo value `AIFP4:<intentHash>` as the link between off-chain authorization and on-chain settlement.

Target story: intent -> policy -> route -> settlement -> receipt.
