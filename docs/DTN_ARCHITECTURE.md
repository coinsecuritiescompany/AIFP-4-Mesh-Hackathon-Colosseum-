# Disruption-tolerant delivery

Payment intents are signed independently of network delivery. The origin stores a payment bundle in its own per-node SQLite WAL database before transport submission. Each relay validates the complete signed envelope, expiry, path, peer identity and protected intent, then atomically stores the bundle, inbox entry and replay marker. A signed `HOP_ACCEPTED` acknowledges that durable local record. This is an AIFP application ACK; it is not a BPv7 custody signal or settlement receipt. ACK and receipt bundles are routed independently and may return over other peers.

The delivery coordinator retries unaccepted whole envelopes with bounded backoff and a fresh signed wire message ID. The original payment identity and bundle ID remain stable. A delayed acceptance for a previously submitted message ID remains valid while that hop record retains it. The route planner can choose another live edge or leave work queued until a path returns. Signed path history and hop limits prevent loops. The settlement node persists its execution state and refuses to execute an uncertain external outcome again. The origin marks settlement only after verifying the signed receipt.

Queue limits are 64 active bundles, at most 32 payments, 16 receipts and 16 ACKs, 16 per origin and kind, 64 KiB per bundle and 4 MiB in aggregate per node. Exhaustion refuses inbound custody before emitting an ACK. Receipts run ahead of ACKs and payment bundles. These are local limits, not a global guarantee. Messages and retries expire with the underlying intent. TCP and libp2p use bounded CBOR fragments and persist partial reassembly. There is no selective missing-fragment ACK or resend. See [the delivery model](DELIVERY_MODEL.md) for the distinct IDs and remaining crash boundaries.

This design uses disruption tolerance and convergence-adapter ideas, but does not implement RFC 9171 BPv7, RFC 9172 BPSec or RFC 9174 TCPCLv4. No interoperable BPv7 sidecar is present. A real daemon and disconnection/recovery interoperability test are required before those claims change.
