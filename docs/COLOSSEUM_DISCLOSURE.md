# Colosseum Development Disclosure

AIFP-4 protocol research existed before the current Colosseum competition. That prior work is treated as pre-existing material and is not represented as hackathon-period development.

The new AIFP-4 Mesh MVP in the repository root focuses on:

- local-first payment intents;
- delegated spend-policy enforcement;
- route ranking and offline queueing;
- deterministic receipts;
- Solana Devnet settlement proof with an on-chain memo tied to the intent hash;
- runnable sandbox API, OpenAPI contract, tests and CI.

Pre-existing material that was reviewed for reuse is kept separately under `legacy/`.
