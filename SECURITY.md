# Security

AIFP-4 Mesh v0.1.0 is a hackathon sandbox and is not production-ready.

Use disposable Devnet accounts and test assets only. Keep all runtime credentials outside the repository. Production deployment requires hardened authentication, managed signing keys, persistent audit logs, rate limiting, monitoring, external review and rail-specific controls.

Please report security issues privately to the AiFinPay team rather than publishing exploit details in a public issue.
